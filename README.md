# ระบบทะเบียนคุมออกหมายจับ 47 และ 47 ทวิ

ระบบสารสนเทศทะเบียนคุมการออกหมายจับ 47 และ 47 ทวิ พัฒนาตามข้อกำหนดของศาลยุติธรรม รองรับการทำงานผ่านเว็บแอปพลิเคชันร่วมกับ **Google Sheets** (แท็บ `DATA` และ `USERS`)

---

## 📌 คุณสมบัติเด่นของระบบ

1. **การกรอกเลขหมายจับ (ข้อ 1)**:
   - ช่องกรอกตัวเลข + Dropdown เลือกปี พ.ศ. (ปี พ.ศ. ปัจจุบันแสดงผลก่อนเสมอ และย้อนหลังได้ 20 ปี)
   - บันทึกจัดเก็บในรูปแบบ `ตัวเลข/ปี พ.ศ.` (เช่น `15/2569`)

2. **การกรอกเลขคดีดำ (ข้อ 2)**:
   - ช่องกรอกตัวอักษรนำหน้า (มีระบบเก็บประวัติ Autocomplete Dropdown เมื่อคลิกเมาส์ และกรองตามตัวอักษรที่พิมพ์)
   - ช่องกรอกตัวเลข + Dropdown เลือกปี พ.ศ. (ย้อนหลัง 20 ปี)
   - **แสดงผลตัวอักษรและปี พ.ศ. เป็นสีดำ** ตามระเบียบข้อบังคับ

3. **การกรอกเลขคดีแดง (ข้อ 3)**:
   - ช่องกรอกตัวอักษรนำหน้า (มีระบบเก็บประวัติ Autocomplete Dropdown เมื่อคลิกเมาส์ และกรองตามตัวอักษรที่พิมพ์)
   - ช่องกรอกตัวเลข + Dropdown เลือกปี พ.ศ. (ย้อนหลัง 20 ปี)
   - **แสดงผลตัวอักษรและปี พ.ศ. เป็นสีแดง** ตามระเบียบข้อบังคับ

4. **ส่วนที่ออกหมายจับ (ข้อ 4)**:
   - Dropdown รายชื่อส่วนงานครบทั้ง 9 ส่วน:
     1. ส่วนช่วยอำนวยการ
     2. ส่วนคลัง
     3. ส่วนบริหารจัดการคดี
     4. ส่วนบริการประชาชนและประชาสัมพันธ์
     5. ส่วนช่วยพิจารณาคดี
     6. ส่วนไกล่เกลี่ยและประนอมข้อพิพาท
     7. ส่วนเจ้าพนักงานคดี
     8. ส่วนเจ้าพนักงานตำรวจศาล
     9. ส่วนเทคโนโลยีสารสนเทศ

5. **วันเดือนปี (พ.ศ.) ที่ออกหมายจับ (ข้อ 5)**:
   - Datepicker ภาษาไทย แสดงผลเป็นปี พ.ศ. (เช่น `16 ต.ค. 2569`)

6. **ระบบการดึงข้อมูลและแสดงผล (ข้อ 8 & 10)**:
   - ดึงข้อมูลเพื่อแสดงผลผ่าน **CSV** จาก Google Sheet แท็บ `DATA` ผ่าน PapaParse
   - แสดงผลตารางผ่าน **DataTables**
   - หน้าแรกแสดงรายการหมายจับ 47 แยกตารางกับหมายจับ 47 ทวิ คนละตาราง (เริ่มต้น 5 รายการล่าสุด)
   - ปุ่มใต้ตาราง "ดูรายการทั้งหมด (View All)" พร้อมแสดง **SweetAlert Progress Bar** ไล่เฉดสีจากขาวไปเขียว พร้อมตัวเลข %

7. **ระบบความปลอดภัยและระดับสิทธิ์ (ข้อ 6, 7, 9, 11, 12, 13)**:
   - ล็อกอินก่อนเข้าใช้งาน
   - ผู้ใช้งานเริ่มต้น: `admin` / รหัสผ่าน: `caogikojt02` (สิทธิ์ admin)
   - สิทธิ์ `admin`:
     - มีเมนู **จัดการผู้ใช้งาน** ใน Sidebar
     - เพิ่ม ลบ แก้ไข ข้อมูลผู้ใช้และสร้าง admin เพิ่มเติมได้
     - **ระบบล็อกป้องกันไม่ให้ลบ user : admin เด็ดขาด**
     - แก้ไขหรือลบหมายจับได้ทุกรายการ
   - สิทธิ์ `user`:
     - กรอกข้อมูลหมายจับได้
     - แก้ไข/ลบได้เฉพาะรายการที่ตนเองเป็นคนบันทึกเท่านั้น (`created_by === username`)

## 🚀 ขั้นตอนการติดตั้งและเชื่อมต่อ Google Sheets & Apps Script

### 1. เปิด Google Sheet
ลิงก์ชีต: [https://docs.google.com/spreadsheets/d/1uhvnk1kRMmZRs1ZyKGjDK75s1ZJSekBJWu-IMt_ZdcA/edit](https://docs.google.com/spreadsheets/d/1uhvnk1kRMmZRs1ZyKGjDK75s1ZJSekBJWu-IMt_ZdcA/edit)

### 2. ติดตั้ง Google Apps Script (`Code.gs`)
1. ในหน้า Google Sheet ให้คลิกเมนู **ส่วนขยาย (Extensions)** > **Apps Script**
2. คัดลอกโค้ดทั้งหมดจากไฟล์ `Code.gs` ไปวางแทนที่ในโปรเจกต์
3. ในแถบเมนูด้านบน เลือกฟังก์ชัน **`initialSetup`** แล้วกดปุ่ม **เรียกใช้ (Run)** ครั้งแรก เพื่อสร้างแท็บ `DATA` และ `USERS` พร้อม User `admin` อัตโนมัติ
4. กดปุ่ม **ทำให้ใช้งานได้ (Deploy)** > **การทำให้ใช้งานได้รายการใหม่ (New deployment)**
5. เลือกประเภท: **เว็บแอป (Web app)**
   - **คำอธิบาย**: ระบบทะเบียนคุมออกหมายจับ
   - **ดำเนินการในฐานะ (Execute as)**: ฉัน (Me)
   - **ผู้มีสิทธิ์เข้าถึง (Who has access)**: ทุกคน (Anyone)
6. กด **ทำให้ใช้งานได้ (Deploy)** และคัดลอก **URL เว็บแอป** ที่ได้รับ

### 3. นำ URL เว็บแอป มาใส่ในระบบ
- เข้าสู่ระบบเว็บด้วย `admin` / `caogikojt02`
- ไปที่เมนู **ตั้งค่า Google Sheet** ใน Sidebar
- นำ URL เว็บแอปที่ได้จากการ Deploy มาวาง แล้วกด **บันทึกการตั้งค่า**
